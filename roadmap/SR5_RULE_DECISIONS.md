# SR5 Rules Decision Register

This register prevents ambiguous or conflicting text in the approved PDFs from
becoming an accidental implementation decision. `Source-resolved` entries may be
implemented as cited. `Owner decision required` entries block their affected
slice until the project owner records a selection, reviewer, and date.

| `identity.license-no-global-legalization` | A license's item/activity type (`identity.fake-license-link`) is recorded as bounded free text (`LicenseSelection.Subject`), not a reference to a specific gear item or a cross-cutting legality flag. `IdentityEvaluator` never reads `Availability.Legality` and returns only a fresh local `CanonicalIdentities` record with no shared/static state, so a license can describe carrying a Forbidden item in flavor text but can never suppress that item's own Availability-12/legality checks elsewhere on the sheet.
